Three steps. Any direction.

  1. 1

    Open it

    Open Open Transfer on your devices. They appear in each other’s Nearby devices within seconds.

  2. 2

    Pick

    Tap one device, several, or Select all — then choose or drop files. Or drop files straight onto a device.

  3. 3

    Accept

    The other device asks “Gaming PC wants to send you 3 files”. Paired devices skip the question.

Everything you’d expect. Nothing you don’t.

Finds nearby devices

Devices on your Wi‑Fi discover each other automatically and show their name and type. Any device can send to any other.

Device to device

Files stream directly to every recipient at once — no server in the middle, no cloud, no size caps.

Pair with a code

Scan a QR code or type 6 digits once; paired devices accept each other’s files automatically. “Paired only” keeps strangers out.

One, some or everyone

Recipients are always shown before you send, and sending to everyone asks first. Progress, cancel and retry per device.

No app? Use a browser

iPhones, iPads and any other device join from the browser by scanning a device’s QR code — and can send and receive too.

Open & scriptable

MIT licensed. Docker image, reverse-proxy support and a small HTTP API for curl.

Feels at home on every screen.

Run from source

Python 3.10+. One command sets everything up.

git clone https://github.com/itsonu/open-transfer.git
cd open-transfer
./run.sh          # Windows: .\run.ps1

Self-host with Docker

For a NAS, home server or Raspberry Pi.

docker run -d -p 5000:5000 \
  -v "$PWD/uploads:/data" \
  ghcr.io/itsonu/open-transfer

Questions

Is it safe?

Files never leave your network, and nothing arrives without the receiver accepting it (or a pairing). Pairing never sends the code in clear. Transfers on the LAN are not encrypted yet, so use networks you trust and “paired only” on shared Wi‑Fi. It also includes CSRF and DNS-rebinding protection, rate limiting, a strict Content-Security-Policy and path-safe file handling. See the security policy.

Does the other device need the app?

Not necessarily. With the app (Windows, Mac, Android) devices find each other automatically. Without it — iPhone, iPad, a smart TV — scan a device’s QR code to join from the browser.

My phone can’t open the link.

Make sure both devices are on the same Wi‑Fi (guest networks often isolate devices) and that your computer’s firewall allows Open Transfer on private networks.

Is there a file size limit?

Only your free disk space. You can set one with --max-size 4G.
